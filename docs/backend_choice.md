# Выбор инфраструктуры Backend

## Сравнение вариантов

| Критерий | Supabase (Free) | Self-hosted (PostgreSQL + Docker) |
|---|---|---|
| Стоимость | $0 | VPS от $5/мес — не бесплатно |
| Развёртывание | 5 минут | 1-2 часа |
| REST API | Автоматический | Нужно писать вручную |
| Auth | Встроенный | Нужно писать вручную |
| RLS | Из коробки | Из коробки |
| Логи | Встроенные | Нужно настраивать |
| Maintenance | Не требуется | Требуется (обновления, бэкапы) |
| Ограничения Free | 500 MB, 50k MAU | Нет |

## Выбранное решение: Supabase Free

**Причины:**
1. Полностью бесплатно в рамках учебного проекта.
2. Не требует VPS и обслуживания.
3. Автоматически генерирует REST API на основе схемы.
4. Встроенная аутентификация (email/password, OAuth2, magic link).
5. RLS настраивается декларативно через SQL.
6. Логи и метрики доступны в dashboard.
