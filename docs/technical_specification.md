# Техническое задание — HabitFlow

## 1. Описание проекта

**HabitFlow** — веб-приложение (PWA) для отслеживания личных привычек. Минималистичный интерфейс, мотивация через streak, offline-режим.

## 2. Целевая аудитория

- Мужчины и женщины 18–45 лет.
- Интересуются саморазвитием.
- Пользуются мобильными приложениями ежедневно.

## 3. Функциональные требования

### 3.1. Создание привычки
- Поля формы: название (обязательное, ≤50 символов), иконка (эмодзи), периодичность (ежедневно / по дням недели).
- Валидация на клиенте и сервере.
- После сохранения — привычка появляется в списке с сегодняшней датой.

### 3.2. Отметка выполнения
- Нажатие на карточку привычки за сегодня.
- Повторное нажатие — снимает отметку.
- Streak увеличивается при первой отметке дня.
- Streak сбрасывается при пропуске дня (кроме случаев, когда периодичность не ежедневная).

### 3.3. Просмотр статистики
- Календарь за текущую неделю.
- Процент выполнения.
- Streak (текущий и максимальный).
- График за 30 дней (опционально).

### 3.4. Редактирование привычки
- Открытие формы с текущими данными.
- Те же валидации, что при создании.
- Обновление отображается сразу.

### 3.5. Удаление привычки
- Подтверждение через модальное окно.
- Удаление безвозвратное (с возможностью отмены в течение 5 секунд).

## 5. Описание обработки ошибок

### 1. Ошибки валидации
**Сценарий:** пользователь вводит пустое название привычки.
**UX-решение:** Кнопка «Сохранить» неактивна. Под полем появляется подсказка красного цвета: «Введите название».
**Сценарий:** название длиннее 50 символов.
**UX-решение:** Счётчик символов меняет цвет на красный при 45+. Кнопка блокируется, подсказка «Максимум 50 символов».

### 2. Отсутствие данных
**Сценарий:** у пользователя нет ни одной привычки.
**UX-решение:** Пустой экран с иллюстрацией (эмодзи 🎯). Заголовок «Начни с первой привычки». Крупная кнопка «Создать привычку».
**Сценарий:** нет отметок за неделю.
**UX-решение:** В статистике — сообщение «Пока нет данных за эту неделю». Кнопка «Отметить сегодня».

### 3. Сетевые ошибки
**Сценарий:** нет интернета при синхронизации.
**UX-решение:** Баннер сверху «Нет подключения. Данные сохранятся локально». Все действия работают в offline-режиме.
**Сценарий:** сервер вернул 500.
**UX-решение:** Модальное окно «Что-то пошло не так. Попробуйте позже». Кнопки «Повторить» и «Работать офлайн».

### 4. Неавторизованный доступ
**Сценарий:** токен истёк.
**UX-решение:** Редирект на экран входа. Сообщение «Сессия истекла. Войдите снова».
**Сценарий:** попытка открыть чужую привычку.
**UX-решение:** Ошибка 403 → экран «Доступ запрещён». Кнопка «На главную».
