## User Journeys

### Счастливый путь (Анна)
1. Открывает приложение.
2. Видит пустой экран → нажимает «+».
3. Заполняет форму: название, иконка, периодичность.
4. Сохраняет → привычка в списке.
5. Нажимает на карточку → streak = 1.

### Негативные сценарии
- Пустое название при создании.
- Потеря интернета (offline-режим).
- Истёк токен авторизации.

## User Stories

### Must have

**US-1. Создание привычки**
> Как пользователь, я хочу создать новую привычку, чтобы начать её отслеживать.

- **Приоритет:** Must have
- **Acceptance Criteria:**
  - **Given** я на главном экране, **When** нажимаю «+» и заполняю форму, **Then** привычка появляется в списке.
  - **Given** поле «Название» пустое, **When** нажимаю «Сохранить», **Then** кнопка неактивна + сообщение «Введите название».

**US-2. Отметка выполнения**
> Как пользователь, я хочу отметить привычку выполненной за сегодня, чтобы зафиксировать прогресс.

- **Приоритет:** Must have
- **Acceptance Criteria:**
  - **Given** сегодняшний день не отмечен, **When** нажимаю на карточку, **Then** карточка подсвечивается, streak = +1.
  - **Given** привычка уже отмечена, **When** нажимаю повторно, **Then** отметка снимается, streak = −1.

**US-3. Просмотр статистики**
> Как пользователь, я хочу видеть свой прогресс, чтобы поддерживать мотивацию.

- **Приоритет:** Must have
- **Acceptance Criteria:**
  - **Given** есть отметки за неделю, **When** открываю статистику, **Then** вижу календарь и % выполнения.
  - **Given** нет отметок, **When** открываю статистику, **Then** вижу сообщение «Пока нет данных».

### Should have

**US-4. Редактирование привычки**
> Как пользователь, я хочу редактировать привычку, чтобы исправить название или периодичность.

- **Приоритет:** Should have
- **Acceptance Criteria:**
  - **Given** привычка существует, **When** нажимаю «Редактировать», **Then** открывается форма с текущими данными.

**US-5. Удаление привычки**
> Как пользователь, я хочу удалять привычки, чтобы убрать ненужные.

- **Приоритет:** Should have
- **Acceptance Criteria:**
  - **Given** привычка существует, **When** нажимаю «Удалить», **Then** показывается подтверждение.

### Nice to have

**US-6. Напоминания**
> Как пользователь, я хочу получать напоминания, чтобы не забывать про привычку.

- **Приоритет:** Nice to have
- **Acceptance Criteria:**
  - **Given** настроено время, **When** наступает момент, **Then** приходит push-уведомление.

**US-7. Тёмная тема**
> Как пользователь, я хочу переключать тему, чтобы комфортно пользоваться вечером.

- **Приоритет:** Nice to have
- **Acceptance Criteria:**
  - **Given** тема светлая, **When** нажимаю «Тёмная», **Then** все экраны меняют палитру.
