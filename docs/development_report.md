### 7.1. Найденные проблемы (до рефакторинга)

| Файл | Проблема | Влияние |
|---|---|---|

### 7.5. Что оказалось наиболее эффективным

1. **React.memo + useCallback** — самый заметный эффект. При добавлении привычки в список из 5+ карточек перерисовывается только новая.
2. **useMemo для фильтрации** — снижает нагрузку при вводе текста в форму (много ререндеров → дешёвые вычисления).
3. **Вынос утилит в lib/** — упрощает тестирование и переиспользование.
4. **JSDoc** — упрощает навигацию по коду и понимание публичного API хука.
