# HabitFlow — трекер привычек

## Проблема
Люди хотят выработать полезные привычки (спорт, чтение, вода), но без визуальной обратной связи быстро бросают. Существующие приложения перегружены функциями и требуют подписки.

## Целевая аудитория
- Мужчины и женщины 18–45 лет.
- Ведут активный образ жизни, интересуются саморазвитием.
- Пользуются мобильными приложениями ежедневно.

## Ключевые функции (MVP)
1. **Создание привычки:** название, периодичность (ежедневно / по дням недели), иконка.
2. **Отметка выполнения:** нажатие на карточку привычки за сегодня.
3. **Статистика:** серия (streak), процент выполнения за неделю, календарь.

## Ценность продукта
- Минималистичный интерфейс — ничего лишнего.
- Мотивация через streak.
- Работает офлайн (PWA).
- Бесплатно, без рекламы.

## Технологический стек
- React 19 + TypeScript + Vite.
- Tailwind CSS 4.
- LocalStorage (MVP) → Supabase (v2).
- Vitest + Testing Library.
