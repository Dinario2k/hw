# HabitFlow — трекер привычек

Веб-приложение (PWA) для отслеживания личных привычек. Проект выполнен в рамках ДЗ №4 курса по разработке с AI-агентами.

## О проекте

HabitFlow помогает вырабатывать полезные привычки через визуальную мотивацию:

- Минималистичный интерфейс — ничего лишнего.
- Streak (серия дней подряд) — мотивация не бросать.
- Работает офлайн — данные хранятся в LocalStorage.
- Бесплатно, без рекламы.

## Функциональность

- ✅ Создание привычек (название, эмодзи-иконка, периодичность).
- ✅ Отметка выполнения за сегодня.
- ✅ Автоматический подсчёт streak.
- ✅ Удаление привычек.
- ✅ Прогресс-бар за текущий день.
- ✅ Пустое состояние с подсказками.
- ✅ Сохранение данных в LocalStorage.
- ✅ Адаптивный интерфейс (mobile-first).

## Технологический стек

| Слой | Технология |
|---|---|
| Язык | TypeScript 5 (strict) |
| UI-фреймворк | React 19 |
| Сборщик | Vite 8 |
| Стили | Tailwind CSS 4 |
| Состояние | useState / useReducer |
| Хранение данных | LocalStorage |
| Тестирование | Vitest 3 + Testing Library |
| Линтер | ESLint 9 |
